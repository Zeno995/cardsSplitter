# Privacy Policy - Cards Splitter

**Last Updated:** December 29, 2024

## 1. Introduction

This Privacy Policy describes how the **Cards Splitter** application ("we", "us", or "the App") collects, uses, and protects users' personal data ("you" or "user").

Cards Splitter is an application for managing accounts during Christmas card games. By using the App, you agree to the practices described in this policy.

## 2. Data Controller

The data controller is the developer of the Cards Splitter application.

## 3. Personal Data Collected

### 3.1 Data Provided Directly by the User

- **Registration data:** email address and password (if you choose email registration)
- **Google authentication data:** name, email address, and profile photo (if you choose to sign in via Google Sign-In)
- **Display name:** the name chosen by the user to identify themselves in game sessions

### 3.2 Data Generated by App Usage

- **Game session data:** session name, creation date, financial movements between players
- **Unique identifiers:** automatically generated user IDs for account management

### 3.3 Technical Data

- **Anonymous access data:** in case of guest access, a temporary anonymous account is created

## 4. Purposes of Processing

Personal data is processed for the following purposes:

1. **Service delivery:** enabling the use of App features, including creating and managing game sessions
2. **Authentication:** verifying user identity and managing access
3. **Synchronization:** enabling real-time session sharing across multiple devices
4. **Account management:** allowing users to update their personal information

## 5. Legal Basis for Processing

Data processing is based on:

- **Contract performance:** processing is necessary to provide the service requested by the user
- **Consent:** for the use of Google Sign-In and for optional features

## 6. Data Retention

Personal data is retained for the time necessary for the purposes for which it was collected:

- **Account data:** retained until the user deletes their account
- **Game session data:** retained until the session or account is deleted

## 7. Data Sharing

Personal data is **not sold to third parties**. Data may be shared with:

- **Firebase (Google):** data is stored on Firebase, a Google platform. For more information, see [Google's Privacy Policy](https://policies.google.com/privacy)
- **Other players:** display name and movement data are visible to other participants in the same game session

## 8. Data Security

We implement appropriate technical and organizational measures to protect personal data:

- Use of secure connections (HTTPS)
- Secure authentication via Firebase Authentication
- Firestore security rules to limit data access

## 9. User Rights

In accordance with GDPR, you have the right to:

- **Access:** obtain confirmation of processing and access your data
- **Rectification:** correct inaccurate or incomplete data
- **Erasure:** request deletion of your data ("right to be forgotten")
- **Portability:** receive your data in a structured format
- **Object:** object to processing in certain circumstances
- **Withdraw consent:** withdraw consent at any time

To exercise these rights, contact us at the address provided in the Contact section.

## 10. Children

The App is not intended for children under 16 years of age. We do not knowingly collect personal data from children under 16. If you are a parent or guardian and believe your child has provided us with personal data, please contact us.

## 11. Changes to This Policy

We reserve the right to modify this Privacy Policy. Changes will be published in the App with the update date indicated.

The App uses the following third-party services:

- **Cloud Firestore:** for data storage
- **Google Sign-In:** for access via Google account

We encourage you to review the respective privacy policies of these services.
